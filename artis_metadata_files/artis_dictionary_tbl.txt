datatable_general_name	definition
consumption	"Core ARTIS output table derived from the ARTIS trade table. Each row represents the estimated quantity of a seafood taxon consumed within a country for a given year, HS version, habitat, production method, and end use, reported in live weight equivalent tonnes. The table tracks the estimated consumption flow by retaining both the producing country, the last exporting country, and the consuming country, allowing domestic and foreign sourcing to be distinguished. Note that end use is based on the HS code the species enters in the ARTIS trade disaggregation. Therefore, there is high uncertainty in the end use for domestic consumption, particularly for countries that produce fishmeal but do not export large quantities of fishmeal. Further, excess domestic consumption is estimated in cases where production is recorded but associated trade is not, as can occur when countries act as a flag of convenience or operate a joint venture."
reference_countries	"A reference table of all countries appearing in the ARTIS outputs. Contains country identifiers, country names, and regional classifications."
reference_hs6_taxa_resolution	"A reference table recording the full many-to-many mapping between hs6 codes and production taxa across all HS versions, produced by categorize_hs_to_taxa(). Each row represents a single taxon–hs6 pairing and documents how that pairing was established and at what taxonomic resolution. Where a production taxon could not be matched to an hs6 at its originally reported taxonomic level, it is stepped up the taxonomic hierarchy — from species to genus, family, order, then class — until a match is found, with both the modified taxon name and the nature of that reclassification recorded. "
reference_hs6	A reference table of all hs6 commodity codes in the Harmonic System (HS) chapter 3.
reference_production	"A reference table of the national aquaculture and capture fisheries production data (sourced from FAO) used as inputs to the ARTIS model. Each row represents reported production of a taxon by a country for a given year, in live weight tonnes. Used in solve_qp() and reweight_X() to constrain and reweight the trade composition estimates."
reference_sciname	"A reference table of all taxa appearing in the ARTIS outputs, one row per sciname. Taxonomic names are primarily standardized using FishBase and SeaLifeBase. "
reference_trade_baci	"A reference table of the raw bilateral trade flow data sourced from the BACI database (CEPII), used as inputs to the ARTIS model. Each row represents a reported trade flow between an exporting and importing country for a given hs6 and year, in product weight tonnes. Used in create_snet() to construct the trade matrices solved by the optimization."
trade	"A core ARTIS output table. Each row represents an estimated bilateral seafood trade flow between an exporting and importing country for a given year, hs6 commodity code, and taxa. All weights are reported in live weight equivalents (tonnes)."
